# ME-MARRT — Identity Superstore

An interactive artwork about shopping, identity and SDG 12: Responsible Consumption and Production.

[Live website](https://tttam2702-ui.github.io/SPEC1_A1/)

The site uses HTML, CSS, JavaScript, p5.js, Matter.js and Web Audio. It is a static website with three connected pages:

- `index.html`: the interactive store and About panel.
- `offer.html`: the offer wheel and prize reveal.
- `challenge.html`: the shopping challenge, melting image effects and notifications.

## Run locally

From the project folder:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000/`. Sounds start after a visitor interacts with the page.

## Deployment

GitHub Pages serves the root of the `main` branch. Assets, sound files and local libraries are included in the repository.
