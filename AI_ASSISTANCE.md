# AI assistance and revision

Codex assisted with generating, editing, simplifying, commenting and checking the application code. The student supplied the concept, visual references, media and directions for the interactions. This is AI-assisted work; it should not be described as code written entirely without assistance.

## What changed in the simpler version

- Reduced the experience to a landing page and a challenge page.
- Replaced the physics library with position, speed, gravity, boundary checks and mouse dragging.
- Used p5 drawing functions for shapes, messages and interface elements.
- Used arrays and simple classes to store moving objects and notification windows.
- Used p5 image copying for melting strips and the p5.sound addon for playback.
- Removed the wheel and the custom Web Audio/beat-scheduling system.
- Kept the 1920 × 1080 drawing size, window fitting, comments and separate library credits.

The comments and [LEARNING_GUIDE.md](LEARNING_GUIDE.md) explain the code's purpose. They do not replace the student's review: before submission, the student should read the code, test it and be able to explain how its variables, conditions, loops and functions produce the artwork.

The application files carry AI-assistance and GPL headers. Unmodified library code is credited separately in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
